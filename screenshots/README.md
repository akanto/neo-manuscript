# Screenshots

Made with `bun run screenshots`: the view in Chrome around the Mirador stand-in.

- `visual.png`: LaTeX in Visual mode next to its PDF. Headings, math and references show as they'll look; the cursor's formula shows its source.
- `errors.png`: Source mode, with a LaTeX error marked on its line and counted in the toolbar.
- `markdown.png`: a Markdown file in Visual mode, with its live preview where the PDF would be.
